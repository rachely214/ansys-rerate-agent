# Casing Limits: What Is Fixed vs. What Can Change

Synthetic, but anchored to the real constraints NASA placed on HECC (fixed tip diameter, speed, inlet radii, and Dmax/D2 of 1.45).

## Fixed (the "walls")

| Item | Limit |
|---|---|
| Rotational speed | 21,789 rpm at 100%; mechanical limit 105% |
| Impeller exit diameter | 17.00 in maximum (cannot grow) |
| Inlet flowpath | Hub 3.19 in and shroud 8.479 in diameter at blade inlet, unchanged (inlet casing reused) |
| Outer stage diameter | 24.65 in maximum (Dmax/D2 of 1.45) |
| Axial length, bearing span, shaft, coupling | Unchanged |
| Inlet and discharge flanges, foundation | Unchanged |
| Driver | Existing; shaft power no more than +6% over current |

## Can change (the "cabinets")

| Item | Allowed range |
|---|---|
| Impeller blades | New impeller: blade angles, backsweep, thickness, lean, blade count free, inside the fixed diameters above |
| Impeller exit blade height | 0.609 in today; up to 0.650 in with a new shroud insert |
| Vaned diffuser | New vanes allowed (count, stagger, shape) between 18.30 and 22.40 in diameter |
| Diffuser channel height | Must match new impeller exit height within 0.010 in |
| Exit guide vanes | May be re-staggered or replaced within existing space |
| Cold tip clearance | 0.010 to 0.014 in |

## Engineering judgment notes for the agent

- More flow with a fixed inlet diameter raises inducer tip relative Mach number. Watch shock losses and choke margin.
- Raising exit blade height adds flow capacity but can hurt efficiency and stability if the diffuser is not rematched.
- Changing diffuser vane count changes the vibration excitation the impeller sees. Re-check the Campbell diagram.
