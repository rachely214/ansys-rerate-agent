# Existing Machine Datasheet

Machine: NASA High Efficiency Centrifugal Compressor (HECC), vaned diffuser configuration, rig scale.
Source: Braunscheidel et al., AIAA 2014-3632 (NASA Glenn), Tables 1, 2, 4, 5. All values published.

## Operating point

| Parameter | Value |
|---|---|
| Design corrected speed | 21,789 rpm |
| Impeller exit tip speed | 1,615 ft/s |
| Exit corrected flow (design) | 3.0 lbm/s |
| Inlet corrected flow, measured | 10.85 lbm/s (design intent 11.2 at 14.7 psia, 11.1 at 11 psia) |
| Total pressure ratio, measured | 4.68 (design intent 4.85 at 14.7 psia, 4.80 at 11 psia) |
| Adiabatic efficiency t-t, measured | 0.822 (design intent 0.862 at 14.7 psia, 0.850 at 11 psia) |
| Polytropic efficiency t-t, measured | 0.855 |
| Stability margin at 100% speed, measured | 7.5% (design intent 12%) |
| Work factor, measured | 0.81 |
| Test inlet pressure | about 11 psia (suppressed inlet, facility limit). All measured values above are at this condition. |
